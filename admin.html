自动写回 GitHub

部署后端接口后，这里可以把当前选好的图片直接覆盖到 GitHub 仓库对应位置。GitHub Token 只保存在后端，不会放在这个网页里。

需要先部署后端接口，再使用这个功能。

上传到 GitHub 的简单步骤

  1. 点击上方 导出 GitHub 图片包，得到一个 zip 文件。
  2. 把 zip 文件解压，里面会有 images 文件夹。
  3. 打开 GitHub 仓库，进入对应目录，例如 images/A-GY25302US 或 images/A-GY25302US/A+。
  4. 把解压后的图片上传并覆盖旧图片，等待 GitHub Pages 自动刷新。
